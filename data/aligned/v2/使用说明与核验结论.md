# 扩展对齐面板 v2：使用说明与核验结论

本轮以项目规则v1.3第5.9节及原v1.3整合表为依据，对全部32项指标逐项记录统计期、时区、发布时间、修订、纳入条件和缺口。已新增10项输入，形成4331行、21列的历史条件版面板。**不是全部历史时点已认证的数据集，也没有把全部32项强行接入。**

## 先看哪个文件

建模输入文件是 [基础建模_扩展对齐_v2.csv](./基础建模_扩展对齐_v2.csv)。18项输入、目标交易日、北京时间信息截止时刻和一个目标y，共21列。日期为2010-01-04至2026-10-12，4330行有y；10月12日目标仍未公布，y留空。项目其他记录已归档的10月9日Wind截图，经检查用于补齐10月9日答案，以及10月12日最新Brent104.72、WTI91.85输入；已记录的处理观察时刻为10月12日北京时间10:33:35，不冒充原始发布时间，也没有倒填到10月9日预测输入。

每行回答：“在这个伦敦原油交易日北京时间12:00前，按列明的历史可用性假设，我们能选择哪些已公布的数据，预测这个交易日的Brent结算价？”列里的周/月数据仍保留原统计周/月，仅在下一份报告可用后更新。不是把各国同名日期当作同时发生。

原8项历史输入及y仅有两处明确的新观测更新：10月9日y和10月12日Brent输入；其余逐值保持原样。CSV不含插补、收益率、均线、标准化、缩尾或额外预测标签。y不是同一行输入。字段单位见 [字段与单位.csv](./字段与单位.csv)，目标来源见 [目标日期与目标值审计.csv](./目标日期与目标值审计.csv)。

## 18项输入包括什么

| 频率 | 输入 | 本轮新增 |
|---|---|---|
| 日度，8项 | Brent连续结算、VIX收盘、OVX收盘；WTI连续期货结算、纽约港柴油现货、纽约港常规汽油现货、Cushing WTI现货、Fed广义美元指数 | 后5项 |
| 周度，7项 | 商业原油库存、汽油库存、馏分油库存、炼厂利用率、原油产量；原油进口、原油出口 | 后2项 |
| 月度，3项 | 非农就业月增减、未季调CPI同比、季调失业率 | 全部3项 |

WTI现货与WTI期货分列；Fed广义美元指数没有覆盖Wind美元指数。三个BLS月度输入使用当月公告数值，与今天Wind中的修订历史不同属于正常情况。

## 怎样核对并对齐

完整逐项规则、官方链接、对应原始Wind文件和暂缓原因，在 [全部指标时间规则与纳入依据.csv](./全部指标时间规则与纳入依据.csv)。34行对应原清单32项及2项独立补充指标；这不是34项都已认证。

1. **EIA周报**：追溯实际每份报告日期和表格。进口/出口取Table1当期周均日量；原油进口按含SPR口径，单位千桶/日。价格只取Table11/12日度列，排除月均和周均列。普通周三10:30美东发布，节假日和延迟按档案实际日期处理。[官方WPSR及档案入口](https://www.eia.gov/petroleum/supply/weekly/)
2. **BLS月报**：公告头逐份核对发布日期、08:30美东及参考月份，时区用America/New_York处理夏令时。非农是CES包含12日的工资期统计，失业率是CPS包含12日的参考周统计，不能把二者都说成月末观测。归档公告与今天修订数据库区分。[就业公告](https://www.bls.gov/bls/news-release/empsit.htm)、[CPI公告](https://www.bls.gov/bls/news-release/cpi.htm)
3. **Fed H10**：核对每份页面Release Date及BROAD、JAN06=100字段；正常周一16:15美东发布前一周日值，联邦假日改期。仅从2019-06-24新基期版本公布后使用，不拿今天新权重历史回填2019年前。[官方H10](https://www.federalreserve.gov/releases/h10/)
4. **WTI期货**：原Wind导出为ICE WTI连续结算，沿用原数值，不替换为NYMEX或EIA现货。ICE通常19:28—19:30伦敦时间结算；渠道历史到达、连续版本没有独立认证。[ICE WTI合约](https://www.ice.com/products/213/WTI-Crude-Futures)、[交易安排](https://www.ice.com/publicdocs/Trading_Schedule.pdf)

### 官方时间与本表假设要分开

官方截止边界仍是**目标日北京时间12:00**，没有擅自改为11:30。实际团队流程可以另定提前量，但不改变这份表。

官方公告形成时间不能直接证明Wind或免费CSV何时收到。原8项继承旧条件版假设；新增公告档案主要假设“实际发布日期结束后的UTC次日00:00可获得”，WTI期货假设“观测日结束后的次日伦敦00:00可获得”。这使正常美国晚间公告从下一北京时间日进入，但**不是渠道延迟已经认证**。Cushing WTI已实际采集的当前快照只从记载的真实接收时点后使用，没有倒填过去。

每个输入的观测期、公告日期、能核实的发布时间、采用的可用时刻、版本、来源单元格和SHA256，在 [逐行输入来源追溯.csv](./逐行输入来源追溯.csv)，共77958条。发布时间和假设可用时刻分列，不互相冒充。

## 已发现并处理的例外

- 非农2020年4月报告：原公布值与5月11日更正分别保留。5月11日中午预测仍用原值−20500千人，5月12日才进入更正值−20537千人；未把后来的更正倒填原公布日。
- 4份CPI公告未成功获取：2024年2、3、4、7月观测期；该期应进入但原值不明，保留缺失。没有偷偷跳回较早非空月份。已核对其他公告的重发说明，相关字段未受影响的才保留。
- 5份H10请求日期与实际页面声明日期冲突：2019-11-12、2020-01-06、2020-01-13、2020-01-21、2020-05-18；另2019-08-26页面404。对应缺口保留空白，没有把后来的报告提前归到请求日期。
- EIA延迟报告同日重复发布（2022-06-29、2023-11-15）：特殊补发与正常报告独立保存，未以文件夹日期相同覆盖；选择截止前最近观测期。
- EIA 2019-07-03 Table1错期CSV沿用已核验的正确PDF。报告目录和HTML声明日期冲突沿用旧规则取较晚日期的条件上界。
- 日度价格最新原始记录是节假日空白时，仍保留空白，不自动跳回较早报价。这可能产生短期缺失，属于本轮“只整合”的约束。

## 为什么还有16项暂缓

| 原指标 | 确定的部分 | 缺什么、怎样补 |
|---|---|---|
| D05/D08/D09/D10，四期限美国国债收益率 | H15工作日16:15美东；收益率单位%；会出现更正 | 要DGS2/DGS5/DGS1/DGS10历史实时期版本或逐日H15原公告。ALFRED公开导出反复超时，未取得可验证文件；不能用当前修订历史加一天冒充历史版本 |
| D20/D24，季调全项目/能源CPI同比 | BLS发布时间及季调年度修订机制 | 要CPIAUCSL/CPIENGSL同一历史可见版本下本月和上年同月指数；不能混版本，也不能用今日修订指数回算 |
| D06，Wind美元指数 | 原文件、数值存在 | 完整代码与编制身份，之后选对应的收盘及发布规则 |
| D07，伦敦黄金 | LBMA AM10:30/PM15:00伦敦，免费发布还可能延迟到午夜 | Wind到底是AM、PM还是另一现货字段；渠道获取规则 |
| D25/D26/D31，上海黄金/白银/INE原油的美元值 | 原始Wind文件存在；交易地时区为北京时间 | 原生人民币计价转换美元的汇率、单位、日期及获取时刻；夜盘交易日归属和具体结算字段 |
| D27，加元 | 按已有决定暂修正单位文字为美元/加元 | CME具体合约代码、结算字段、窗口和连续版本；修改单位标签不能认证底层合约 |
| D28，IPE轻质原油 | 原文件存在 | 原合约身份、完整代码；不能凭IPE简称认定Brent或WTI |
| D29/D30，英国/TTF天然气美元值 | 英国NBP候选结算16:05—16:15伦敦；TTF原生欧元/MWh | 具体代码与USD转换。TTF末交易日18:00不能当作每日结算时间；需对应合约每日规则 |
| D32，NYMEX汽油 | 原文件单位美元/加仑；候选产品为RBOB RB | Wind具体代码、美元/美分缩放、连续字段与汽油结算窗口的对应关系；此前误写天然气已更正 |

前6项主要缺历史版本，后10项主要缺Wind字段身份/币种转换说明；详细程度不同，但均已逐项写入规则表。[ALFRED实时期下载说明](https://alfred.stlouisfed.org/help/downloaddata)、[H15官方说明](https://www.federalreserve.gov/releases/h15/)、[BLS季调说明](https://www.bls.gov/cpi/seasonal-adjustment/)、[LBMA黄金说明](https://www.lbma.org.uk/prices-and-data/lbma-gold-price)。

若使用浏览器人工导出ALFRED，逐个选择上述6个系列，下载类型选Observations by Real-Time Period，CSV压缩包，所有历史版本日期；CPI至少从2008年起覆盖同比所需前一年。必须保留包内README和实时期起止列。普通“当前历史数据CSV”不满足这个缺口。

## 验证与剩余限制

- 4331个目标日期唯一、递增；旧8列和y除上述两处补入的新观测外完全一致。
- 77958条输入追溯记录的已采用可用时刻均早于对应截止边界；有原始值缺失时保持空白。
- 独立复选197条边界日期输入；核对120个原始CSV物理单元格；对3241个实际被选中的源文件校验SHA256。抽查包括普通日、周一、美英夏令时不同时段、节假日、公告前后和更正前后。
- 固定来源重跑后，主表、追溯、规则、单位、目标审计和覆盖情况6份文件逐字节一致，见reproduction_validation.json。
- 原2010—2025目标日期仍以Wind存在结算值的日期为主，未独立补齐全部历史交易所日历。2026沿用已核对日历。不能宣称历史目标日轴全部认证。
- 商业原油库存2016年口径变化以前、周报档案2015年以前、广义美元新基期发布以前留空。不同列覆盖范围不等；不要现在为方便把缺失统一补上。具体见 [各输入覆盖情况.csv](./各输入覆盖情况.csv)。
- 所有公告档案都是本次获取的版本。已发现的重发按说明处理，但未证明所有机构档案从未静默更正；免费渠道历史延迟和Wind连续快照风险仍存在。因此本表支持明确假设下的研究，不能称为严格实时历史认证基准。
- 最新目标前一交易日2026-10-09的Wind Brent/WTI已由项目归档截图补齐；它只证明这次观察到的数值，不证明整个Wind历史序列的到达时间与连续版本。

## 重现

在项目根目录依次运行：

```text
python scripts/parse_bls_release_archives.py
python scripts/normalize_remaining_records.py
python scripts/build_expanded_time_panel.py
python scripts/verify_expanded_time_panel.py
```

Python依赖为openpyxl、lxml、pdfplumber、tzdata；数据处理不需要访问网络，也不修改任何原始文件。重新采集可另运行collect_eia_price_archives.py、collect_eia_price_archives_remaining.py、collect_h10_release_archives.py及repair_remaining_downloads.py；BLS原公告证据和获取日志已保存，失败记录不能直接用修订数据库替代。

后续应先补齐缺少的版本和Wind身份资料，再决定训练样本范围和缺失处理。本轮没有开展模型训练或按结果挑选变量。
