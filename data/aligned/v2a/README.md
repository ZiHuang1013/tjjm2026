用户已确认10月15日WTI保留96.50；此前97.97仅作为当时盘中价归档。10月17日新消息又将97.97明确列入10月16日收盘值，按本次声明记录，不更改10月15日。行情来源是用户消息/原项目归档，未另行认证供应商和合约身份。
