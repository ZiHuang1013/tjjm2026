# 数据面板v2A：假设扩展版

> 以下为10月12日原构建说明，行数、最新日期及重建说明保留为历史记录。当前发布数据与时间对应请优先阅读同目录README.md；完整离线重建另需本地脚本和原始源文件。

本版根据用户授权，尽量把此前暂缓的16项指标纳入探索面板。**原始口径或历史时间不明的部分采用明确假设，不表示问题已核验解决。滞后不能保证消除历史修订、连续序列事后调整、未知转换或长延迟带来的泄漏。**

## 使用哪个文件

主表为 [基础建模_假设扩展版_v2A.csv](./基础建模_假设扩展版_v2A.csv)：4331行，34项输入，加目标交易日、信息截止时刻、目标y，共37列。保留v2的日期主轴与全部原有列和值，新增16列均以`_assumed`结尾，便于模型代码选择或排除。

对应原清单32项全部已表示为输入（Brent为前期结算值输入，目标值单独放y），另有WTI现货和Fed广义美元指数2项独立补充。频率共22项日度、7项周度、5项月度。无插补、缩尾、标准化、汇率转换、收益率构造或模型训练。原始值缺失保持缺失。

这份表用于比较“加入候选数据后有没有额外预测信息”。原v2保留为固定研究参照，勿覆盖原模型固定输入或根据扩展版回测成绩反向认定口径正确。

## 本轮采用的滞后

| 新增组 | 如何假定可用 | 为什么这样做 | 仍不能解决什么 |
|---|---|---|---|
| 10项Wind日度辅助指标 | 本地观测日期d结束，再等待1个完整自然日；即d+2日当地00:00后才候选 | 避开当日尚未形成的完整日值，额外留一天缓冲 | 不证明具体价格字段、转换所用汇率日期或Wind实际到达；超过缓冲的延迟仍有风险 |
| 四期限美国国债收益率 | 观测日期后的第2个美国联邦工作日结束，次日00:00美东后候选 | 为已知的发布滞后及假日留额外缓冲；没有拿美国工作日当伦敦交易日 | 今日历史中的更正值可能在当年截止后才出现；仍非历史当时版本 |
| 两项季调CPI同比 | 统计月结束后等待2个完整自然月；从第三个月1日00:00美东后候选 | 为月度发布时间不明留较长缓冲；不是从月末立即回填 | 季调年度修订可能改写多年历史，等两个月也不能恢复原版本 |

上述滞后是本项目研究设计，不是Wind官方发布规则，也不是根据模型成绩挑出的最优参数。原18项列沿用v2选择，不再统一多滞后一次。美国联邦节假日仅用于国债列的假设缓冲；目标日期仍按v2伦敦原油日期。

所有新增输入仍使用“假定可用时刻严格早于该行北京时间12:00”的条件选择最近观测期。月度先选最新符合条件的统计月；若该月原值缺失，不跳回较早非空月份。日度同理，不跳过原始空值。

**假设例子**：1月季调CPI值从4月1日美东00:00才候选。如果该时刻恰好等于北京时间12:00，则该行仍不能用，下一目标交易日才可进入。这里是人为缓冲示例，不是实际CPI发布日期。

## 16项具体假设

| 编号 | 新增内容 | 怎样理解这列 |
|---|---|---|
| D05/D08/D09/D10 | 美国2年/5年/1年/10年国债收益率 | 单位%，按已核对的统计定义理解；值来自收到的Wind历史快照，历史更正没有去除 |
| D06 | Wind美元指数 | 沿用1973年3月=100源标签；暂视为美元指数日值，不宣称已经认证编制机构和收盘字段；与Fed广义指数分列 |
| D07 | 伦敦黄金美元现货 | 沿用美元/盎司；暂视为当日伦敦黄金报价，不猜AM、PM或其他具体报价 |
| D20/D24 | 全项目/能源季调CPI同比 | 单位%，保留Wind原同比值，不用今日指数另算；修订版本风险较明确 |
| D25/D26 | 上海黄金/白银连续美元值 | 暂按原文件美元/克、美元/千克理解；不重算汇率，也不解释成纯本币商品价格变化 |
| D27 | CME加元兑美元连续 | 暂按1加元值多少美元理解；沿用此前单位文字修正，原数值不倒数、不缩放 |
| D28 | IPE轻质原油连续 | 仅保留源名称的身份，不指认为Brent或WTI；美元/桶沿用标签 |
| D29/D30 | 英国/TTF天然气连续美元列 | 暂接受源文件美元/色姆、美元/兆瓦时标签；转换公式与汇率尚未确认 |
| D31 | INE原油连续美元列 | 暂按上海原油交易日及美元/桶源标签理解；人民币转换、夜盘归属仍未独立认证 |
| D32 | NYMEX汽油连续 | 候选为RBOB汽油，源标签美元/加仑；数值尺度与代码尚未确认，不乘100或除100；不是天然气 |

D25/D26/D29/D30/D31美元转换列可能包含汇率影响；D27报价方向、D28底层产品、D32价格尺度不明时，不能据其数值写确定的经济解释。模型暂时使用某列，不等于这些解释已经成立。

每列完整的原名称、假定单位、原单位、原文件头、时区、滞后和剩余风险见 [新增指标假设与风险.csv](./新增指标假设与风险.csv)。字段单位见 [字段与单位.csv](./字段与单位.csv)。

## 最新截图与数据追溯

项目已归档的10月9日美元指数及10年美债截图也被保留为候选记录，可用假定同时要求滞后结束及实际已记录的接收观察时间通过；没有因为截图已收到就取消该列滞后。例如10月12日10年国债列不会直接用10月9日截图值。

主表中的旧18项输入来源仍使用v2的追溯表。新增16项的每个预测行对应 [发布版全部34项输入来源追溯](./全部34项输入来源追溯.csv)，69296条；包括原观测日期、源单元格、假定可用时刻、源版本和缺失状态。通过indicator_id与source_file_id关联 [原始文件对应.csv](./原始文件对应.csv)，可取得完整原路径及SHA256。假定时刻不是实际发布时间。

本版直接读取3份原Wind工作簿，而不是仅依赖旧整合缓存；读取前验证原始文件SHA256，原值按单元格复制。没有改写任何原始文件或v2。

## 当前赛题规则的额外限制

已核对项目最新规则v1.4第5.10节：截止仍为北京时间12:00，**目标现在明确不复权**。本轮仅扩展候选输入，沿用v2目标和Brent历史值，没有凭假定重新复权或去复权。现有Wind目标序列是否与新版不复权、每次月底换月映射一致，仍待认证；本版不能因此称为完全符合赛事目标口径的数据。

## 检查与下一步

已检查目标日期唯一递增、全部v2列逐值不变、新增输入的假定可用时刻早于边界、原始空值未跳过、源文件哈希和边界日期独立复选。验证只证明代码遵守已声明的假设，**没有证明实际世界不存在泄漏**。各新增列覆盖和缺失数见 [新增指标覆盖情况.csv](./新增指标覆盖情况.csv)。

建议后续先在相同样本、相同时间顺序验证下比较v2与v2A，再分别检查“去掉两项季调CPI”“去掉四项国债”“去掉未确认Wind美元转换列”等结果是否稳定。若收益只依赖高风险列，就不能直接当成可实施的比赛优势。本轮未执行这些模型实验。

可重复运行代码位于项目scripts/build_assumed_extension.py和scripts/verify_assumed_extension.py，依赖openpyxl、pandas、tzdata。依次运行即可重建并检查，不需要联网。
